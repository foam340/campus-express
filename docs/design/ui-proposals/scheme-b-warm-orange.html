CAMPUS EXPRESS · UI PROPOSAL

方案 B · 暖橙快递站

把「快递站票据」做成视觉语言：奶油底、墨色描边、贴纸式硬投影、票券打孔线。比方案 A 更有性格、更年轻，适合想在同学间做出辨识度的定位。绿色只留给「优惠 / 成功」，钱永远用深橙表示。

主色 快递橙 #FF6B2C 底色 奶油 #FFF7EE 描边 暖墨 #241505 优惠 抹茶绿 #1E9E6A 卡片 = 2px 墨线 + 3px 硬投影（贴纸感）

手写批注 · 逐条回应

  • 「图例」→ 上传区内置示例缩略图（墨线描边 + 绿✓），文案「看看合格图例 ›」。
  • 「超大件」→ 独立贴纸条：30kg+ / 冰箱洗衣机，「找客服估价」就在旁边。
  • 「快递1、2金钱区分」→ 卡片右上角单件价格 + 费用明细分行；票券打孔线把「明细」与「应付」分开，金额感更强。
  • 「缩短」→ 首页首屏完成下单主路径，当前订单状态一眼可读。

记忆点与差异

  • 票券打孔线：费用卡片和订单卡片都有「撕票」细节。
  • 贴纸徽章微旋转（-2°~2°）：爆单提醒、预计时间像手贴的小标签。
  • 条纹 Hero + 描边包裹 emoji：活泼但克制，不堆 3D 元素。

落地提示

  • 描边 + 硬投影在低端安卓上渲染开销极低，无模糊阴影。
  • 对比度：暖墨 #241505 / 奶油底 ≈ 13:1；描边文字均 ≥ 4.5:1。
  • 如觉得「贴纸感」过强，可把描边降为 1.5px、去掉旋转，即成中间态。
