CAMPUS EXPRESS · UI PROPOSAL

方案 A · 能量钴蓝

保留现有蓝色品牌认知，把它推向「运动能量感」：更深的钴蓝、更果断的圆角、橙色只出现在价格与加急上——一眼就知道钱在哪、动作在哪。首页 Hero 的虚线航线是整套设计的记忆点：快递从驿站「飞」到宿舍楼下。

主色 钴蓝 #2450E8 强调 活力橙 #FF7A1A 底色 云雾灰蓝 #F2F5FB 正文 蓝调近黑 #141A2E 价格数字 Bahnschrift（DIN 风格）

手写批注 · 逐条回应

  • 「图例」→ 融入上传区：左侧内置 64px 示例缩略图（取件码样式），带绿色✓，文案改为「点此看图例」。
  • 「超大件更具体」→ 独立提示条：30kg+ / 冰箱、洗衣机等，「联系客服」入口就放在同一行。
  • 「快递1、2金钱区分」→ 每张快递卡片右上角显示该件价格；费用明细按快递 1 / 2 分行列出。
  • 「缩短」→ 首页一屏放下 Hero + 状态 + 当前订单，下单动作第一屏可达。

记忆点与差异

  • Hero 虚线航线 + 包裹图形：快递「飞向宿舍」的动线隐喻。
  • 橙色只给价格与加急：金钱信息 3 秒可辨。
  • 悬浮胶囊 TabBar，保留现有形态但加投影层次。

落地提示

  • 全部色值 / 圆角 / 阴影已写成 CSS 变量，可直接映射到小程序 wxss。
  • 数字使用 tabular-nums，金额跳动不抖动。
  • 对比度：正文 #141A2E/#F2F5FB ≈ 14:1；橙底白字按钮已避开（橙只做文字色）。
